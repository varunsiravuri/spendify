# Spendify

Spendify is an autonomous month-end close system for AI and cloud spend, built for the **Autonomous Office of the CFO** track at Syndicate by Maximor.

Spendify reconciles usage telemetry, provider rate cards, invoices, prepaid credits, and accounting policies to produce reviewable exceptions and balanced draft journal entries with complete source lineage.
